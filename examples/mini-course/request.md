# 用微型线性代数课程试跑一次

示例包含一份课程笔记和两份原创虚构样卷。按[首页安装步骤](../../README.md#quick-start)安装技能后，在仓库根目录启动 Codex，把下面整段发给助手。使用 Claude Code 时，将第一行换成 `/exam-prep`。

```text
$exam-prep
请读取 examples/mini-course/materials 内的全部材料。
只覆盖课程笔记中规定的范围。按虚构样卷的 20 分、25 分钟形式，
生成知识总结、一套有新意的模拟卷及单独答案解析，均为 PDF。
保留可编辑源文件、资料清单和真题统计，输出到 exam-prep-output/demo。
```

## 核对本次输出

打开 `exam-prep-output/demo/`，依次核对以下文件。

| 文件 | 核对什么 |
| --- | --- |
| `sources.json`、`exam-analysis.md` | 清单含三份材料。分析以两份独立的虚构样卷为分母；方程组在两卷中各出现一次，记作 2/2。这个频次只描述这两份卷。 |
| `knowledge-summary.pdf` | 范围以课程笔记为准，覆盖行列式、二元方程组、特征值与特征向量；矩阵幂只涉及笔记中的向量分解应用。二次型在范围外。 |
| `mock-exam-01.pdf` | 先独立作答。卷面标明 25 分钟，各题分值合计 20 分，答案单独存放。 |
| `mock-exam-01-answers.pdf` | 作答后按题号核对推导，检查各步评分能否加回该题总分。 |

仓库的[参考成品](preview/)可用来对照文件结构。每次试跑可以生成不同的新题。若环境缺少可用的 PDF 导出工具，检查助手是否保留了可编辑源文件并说明哪些 PDF 尚待生成。
