# 试用请求

在仓库根目录启动已安装技能的 Codex，输入：

```text
$exam-prep
请读取 examples/mini-course/materials 内的全部材料。
只覆盖课程笔记中规定的范围。按虚构样卷的 20 分、25 分钟形式，
生成知识总结、一套有新意的模拟卷及单独答案解析，均为 PDF。
保留可编辑源文件、资料清单和真题统计，输出到 exam-prep-output/demo。
```

Claude Code 将第一行改为 `/exam-prep`。

观察：识别两份独立历史样卷；不把虚构样卷当真实学校考试；不引入二次型；不把 2/2 频次说成必考；题面不含答案；全卷 20 分；每题答案可核验。如果没有 XeLaTeX 或其他导出工具，应明确指出 PDF 尚未生成。
