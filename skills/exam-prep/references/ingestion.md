# 文件提取与来源定位

仅阅读本次遇到的格式路径。格式支持依赖宿主工具；下列工具为可选方案，不要求全部安装。

## 来源记录

`inventory.py` 生成 schema_version=1 的清单。补充字段：

| 字段 | 含义 |
| --- | --- |
| id / path / sha256 | 稳定来源 ID、相对路径、内容哈希 |
| kind / route | 文件类别与建议处理路径，不代表解析成功 |
| status | pending、extracted、partial、unreadable、duplicate |
| duplicate_of | 字节级副本来源 ID，跨格式副本另行核对 |
| coverage | 实际已读范围，例如 PDF 1–28/30 页 |
| locator | pdf_page、slide、sheet_cell、section、line、timestamp 等 |
| issues | 缺页、模糊、编码、加密、未识别图表等 |

ID 不随手工调整清单而重编号。同路径内容变化时保留 ID，更新哈希、缓存与下游分析。ID 不放入题面，但用于总结、分析、答案来源表。

接续清单时，`--reuse-from` 只复用阅读记录。引用原文、页码或公式时仍需能打开上次的提取结果或重新查阅原件。新清单仅列出此次仍在范围内的材料，更新真题分母时也要检查已移除的试卷。

同哈希只证明字节级副本。扫描版与文字版不同哈希也可能是同一卷，需核对课程、年份、卷别、题序与题干。多文件构成一份卷时建立组合关系，不按文件数量统计试卷。

## 格式路由

- **文字 PDF**：使用宿主 PDF 工具、pdftotext 或可用 PDF 库逐页提取。抽查首尾与公式 / 图表密集页，逐页查短文本、乱码并触发 OCR。文字层存在不代表扫描页可读。
- **扫描 PDF / 图片**：旋转、分栏或裁切工作副本，再用视觉或 OCR；保留原图与位置。核对关键符号，不把无法识别的公式替换成常见公式。
- **DOCX**：提取段落、表格、脚注和图片。OMML 公式、文本框、嵌入对象可能被纯文本库遗漏；必要时渲染 PDF 核对。无可信分页时按标题 / 段落定位。
- **PPTX**：逐页读文本、表格、图形、图片、公式与讲者备注。备注按来源标明，重要图示看原页。
- **XLSX / CSV**：保留表名、行列和单元格；区分公式与缓存值，不将旧缓存视为已核验结果。隐藏表有课程内容时也记录。
- **DOC / PPT / XLS**：用可用 Office / LibreOffice 转换副本，保留原件、转换关系并核对结果；转换失败记录未读内容。
- **TXT / Markdown / HTML / 代码**：识别编码，保留标题、列表、表格和代码语义。HTML 去导航但保留图注。代码作为资料阅读，除非任务需要在适当环境执行。
- **音频 / 视频**：可转录时保留时间戳；板书、幻灯片或演示补看画面。只听音轨不代表视觉内容已覆盖，听不清保留不确定区间。
- **ZIP / 7z / RAR / TAR / EPUB**：先列成员、估算体积与嵌套。解压限于工作目录，拒绝越界路径、符号 / 硬链接和异常膨胀成员。EPUB 可按章节解析。保留包与成员来源链。
- **未知 / 专有格式、损坏、加密**：尝试已有工具，失败记录原因并请求可读导出或用户愿意提供的密码。不绕过加密，不虚构内容。

## OCR 与数学

重点核对负号、上下标、根号范围、积分界限、向量粗体、转置、矩阵维度、分段条件和单位。题干与答案可以互相检查，但不为了符合答案擅改题干。

不确定题目可排除出命题依据，但须列明。仅在不可读片段出现的知识点不能形成确定结论。承载必要信息的图表应在成果中重绘或引用带来源的可读图，不能只留下“见图”。
