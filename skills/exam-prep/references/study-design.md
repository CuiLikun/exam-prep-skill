# 学习设计：把整理变成能够使用的知识

在选择复习模式、组织知识总结或处理不同学科时读取本文件。这里的参数是助手执行偏好，不是程序自动实现的配置。

## 1. 三个调节项与套数

用户自然语言优先于默认参数。根据明确目标选择并在 exam-analysis.md 记录；不要要求用户必须填写配置，也不要因为仅剩几天便假定用户已经掌握基础。

| 参数 | 默认 | 可选值与行为 |
| --- | --- | --- |
| STUDY_MODE | balanced | balanced 系统串联；sprint 速查回顾；practice 限时自测 |
| EXPLANATION_DEPTH | standard | compact 精简；standard 标准；detailed 详细 |
| EXAM_DIFFICULTY | aligned | aligned 对齐有效真题；foundation 基础应用；challenge 综合迁移 |
| MOCK_COUNT | 1 | 正整数；明确多套时按要求生成 |

分值、时长、语言和范围另由用户或材料确定。模式只改变组织重点，不改变交付种类；用户未缩小要求时仍交付总结、试卷与独立答案。

### 模式怎样影响成果

| 模式 | 总结编排 | 练习安排 | 保留项 |
| --- | --- | --- | --- |
| balanced | 章节关系、概念、条件、方法、例题、自测 | 先局部应用，再综合卷 | 大纲覆盖和前置知识 |
| sprint | 速查表前置，易混条件与典型错误集中展示 | 代表性题型与一套综合检验 | 公式条件、范围缺口、来源 |
| practice | 以蓝图、易错点和复盘索引为主的简要总结 | 用户先拿到题面，答案独立存放 | 充分解答、评分点、错因解释 |

速记模式不是删除难点的许可；用户说“零基础、两天后考试”时，优先给必要前置知识与取舍说明，不写成只有口诀的速记单。

### 讲解深度

- compact：给结论、适用条件、关键步骤和一个诊断性问题。不得压缩掉条件、单位、符号含义。
- standard：加入典型例题、关键步骤原因、常见误区和自测反馈。
- detailed：展开必要前置知识、逐步推导，并给边界或反例。避免重复同一意思来凑篇幅。

深度主要控制知识总结。任何深度的答案解析均应足以复现解法；推导步骤的给分依据不随篇幅偏好消失。

### 难度

aligned 以可用真题的知识跨度、步骤数、计算量和作答要求为参照；无足够依据时用明示练习设定。foundation 强调理解与基本应用；challenge 增加条件判断、情境迁移或多知识点组合。难度不靠超纲、生僻词或纯粹放大计算量制造。

多套卷沿用同一覆盖蓝图，改变需要作出的判断或推理；不能把简单换数字当作题目多样性。

## 2. 一个知识单元至少回答什么

重要知识点按以下内容组织，不必机械套相同标题：

| 要素 | 应写出的信息 |
| --- | --- |
| 目标 | 学完能辨别、计算、证明、解释或实现什么 |
| 结论与条件 | 概念、定理、公式、边界和必要符号 |
| 识别与方法 | 什么题面信号提示使用此方法，关键步骤为何成立 |
| 例题与误区 | 一个闭合例题，最常见的错误及其失败原因 |
| 自测与依据 | 不看答案能做的短题，简短反馈，以及具体来源 |

先建立依赖关系，再压缩文字。例如秩与相容性是判断线性方程组解的前提；只罗列“求逆、消元、求秩”无法帮助学生选择方法。

自测答案不要贴在问题后第一行。可以集中放到章节末尾的自测答案区，并写明索引；模拟卷的答案始终独立成文件。

## 3. 根据学科改变写法

| 学科任务 | 总结重点 | 好的练习 | 核验重点 |
| --- | --- | --- | --- |
| 数学、物理、工程 | 假设、符号、适用域、推导、量纲 | 条件变化、结果检验、方法选择 | 边界、单位、等价变形、数值代入 |
| 编程、算法 | 数据模型、前置条件、不变量、复杂度 | 边界输入、跟踪执行、实现与解释 | 样例输出、资源限制、复杂度依据 |
| 概念与理论课程 | 定义边界、相似概念、因果链、证据 | 概念辨析、短论证、反例 | 是否偷换概念、结论是否超出依据 |
| 案例与论述课程 | 情境、观点、依据、推理、评价标准 | 新案例与多角度论证 | 评分维度与合理替代观点 |

不要把每门课都做成公式表，也不要把每门课都写成长篇叙述。图仅在解释结构、过程、关系或几何时使用，含义须能由材料支持。

## 4. 质量差的写法如何修正

这些例子展示判断标准，不是课程事实的替代来源。

| 需要修正的写法 | 问题 | 应如何处理 |
| --- | --- | --- |
| “行列式为零，所以方程组无解” | 遗漏相容性判断 | 比较系数矩阵与增广矩阵的秩，再区分无解与无穷多解 |
| “这章历年没考，可以不看” | 以样本缺失推断当前范围 | 回查当前大纲，区分历史覆盖与学习必要性 |
| “时间复杂度 O(n)” | n 的含义和计算模型未定义 | 写清输入规模、主操作次数与前提 |
| “论述题答案如下，必须逐字一致” | 把范文误作唯一答案 | 给评分维度、证据要求和可接受的替代论证 |
| “扫描不清，但应当是这个公式” | 把猜测升级为事实 | 标记待确认、保留原页定位，不用它支撑确定性命题 |

## 5. 时间安排与复盘

已知剩余天数时，先考虑知识依赖、范围重要性和用户薄弱点，再安排时段。不要杜撰预计提分。

每日安排应包含具体章节或任务、练习动作和检查方式，例如“脱离答案重做两道参数分类题，并解释每个分支成立的条件”。没有用户可用时长时，不假设能连续学习十小时。

答案中可标记适用的错因：概念混淆、条件遗漏、方法选择、推导断层、计算错误、表达不足。只有看到用户作答后，才把错因归到该用户；不能仅凭生成的试卷诊断个人弱点。
