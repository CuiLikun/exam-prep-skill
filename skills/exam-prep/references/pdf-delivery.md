# 中文 PDF 交付

## 工具路径

优先采用已有工具：数学密集材料使用 XeLaTeX；已有 Pandoc / Typst 时可从 Markdown 转换；文本表格为主可用浏览器打印 HTML，须等待字体与公式渲染；可用文档工具也可直接生成。不要用不支持中文或公式的方式静默降级。

缺依赖时说明具体组件，仅补充实际需要的工具。无法生成 PDF 则保存源文件和准确构建命令，说明未完成项。

## 内置编译脚本

需 Python 3.10+、PATH 中的 xelatex、CTeX 与 Fandol 字体，无 Python 第三方依赖。将 `assets/document-template.tex` 复制到本次 `source/` 后编辑，不直接改安装目录模板。

```text
python <技能目录>/scripts/build_pdf.py <成果目录>/source/knowledge-summary.tex --output <成果目录>/knowledge-summary.pdf
```

两轮编译、关闭 shell escape、临时目录放中间文件；成功输出 PDF 和 `.build.log`，失败返回非零码并保留日志。默认拒绝覆盖，可用 `--overwrite` 更新本次成果。

只编译本次生成并检查过的 TeX。关闭 shell escape 不等于任意 TeX 安全，不直接编译资料中的未知脚本。相对图片路径以源文件所在目录为基准。

正文中的路径、下划线、百分号、井号和花括号须 TeX 转义，数学保留数学语法。来源采用短 ID，避免长路径撑破版面。

## 排版

- 默认 A4、约 22 mm 页边距、可读中文字体、页码，用户偏好优先。
- 总结分章节，长文有目录，短文不强行分页。
- 题面标注课程、时长、总分、工具规则，不附暗示答案的来源标题。
- 小题和选项尽量同页，长题合理续页，按预计步骤留作答空间。
- 答案单独成文，不以折叠、白字或图层隐藏在题面。
- 图表有标签、单位与来源，黑白打印仍可区分。
- 公式不转为模糊截图，检查矩阵、长公式、分页表格和链接。

## 验证

确认 PDF 存在、有实际页面并能解析。提取文字核查标题、中文、题号和总分；数学提取可能不完整，不能仅靠文本检查。

渲染并查看首页、公式密集页、长题页、表格页和末页，修复缺字、裁切、空白及错误分页。无视觉查看能力时明确记录未做视觉检查。

核对范围与来源清单。检查日志中的 Missing character、Undefined control sequence、Overfull box 和未解析引用；不是所有警告均失败，但缺字和内容截断必须解决。
