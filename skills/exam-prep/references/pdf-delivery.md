# 中文 PDF：阅读、作答与复盘的版式

生成文档时读取本文件。以可读、可打印、可回查为目标；装饰不能挤占讲解或作答空间。

## 1. 选择可靠的导出路径

优先使用已有工具：数学密集材料用 XeLaTeX；已有 Pandoc / Typst 时可从 Markdown 转换；文本表格为主可以浏览器打印 HTML，但须等待字体与公式渲染。适用的文档工具也可直接生成。

不能用不支持中文或公式的方式静默降级。依赖缺失时说明具体组件，仅补充本次需要的工具。无法完成 PDF 则保存源文件与准确构建命令，标记未完成项。

## 2. 使用内置模板与编译脚本

需要 Python 3.10+、PATH 中的 xelatex、CTeX 与 Fandol 字体；脚本无 Python 第三方依赖。将 `assets/document-template.tex` 复制到本次 `source/` 后编辑，不直接改技能安装目录。

```text
python <技能目录>/scripts/build_pdf.py <成果目录>/source/knowledge-summary.tex --output <成果目录>/knowledge-summary.pdf
```

脚本两轮编译，关闭 shell escape，中间文件放临时目录；成功输出 PDF 与 `.build.log`，失败返回非零码并保留日志。默认拒绝覆盖，使用 `--overwrite` 可更新本次成果。

只编译本次生成并检查过的 TeX。关闭 shell escape 不等于任意 TeX 安全，不直接编译资料内未知脚本。相对图片路径以源文件目录为基准。

路径、下划线、百分号、井号和花括号须按正文语境转义，数学表达式保留数学语法。使用短来源 ID，避免长路径撑破版面。

## 3. 三类文档，三种阅读任务

| 成果 | 首屏优先放什么 | 正文组织 | 应避免 |
| --- | --- | --- | --- |
| 知识总结 | 课程、范围、版本、阅读说明 | 章 → 知识单元 → 条件 / 方法 / 例题 / 自测 | 只有目录和无解释的公式墙 |
| 模拟试卷 | 时长、分值、工具规则、作答要求 | 题号、必要条件、小问、分值、作答区 | 将解题标签、来源标题或答案带进题面 |
| 答案解析 | 对应卷名、评分约定 | 与题号同序的结果、推导、步骤分、错因 | 只有最终结果，或者把多个题的解析混在一起 |

短文不必专门做占一整页的封面；长总结添加目录与可用书签。试卷和解析不要共享一个隐藏答案的 PDF：分别生成文件。

## 4. 版式基线

用户偏好优先。没有指定时采用：

- A4、约 22 mm 页边距、可嵌入的中文字体，正文约 10.5–12 pt。
- 清晰的标题层次与页码；同级标题样式一致，来源以较小但可读字号贴近结论。
- 黑白打印仍能区分重点。最多使用少量强调色，不让颜色成为识别条件或答案的唯一线索。
- 长公式分行，矩阵和符号保持文本 / 矢量清晰度；避免模糊截图。
- 表格有列标题，跨页保留阅读上下文；不要把大段推导塞进狭窄单元格。
- 小题与选项尽量同页。长题确需跨页时标明续题，前页不得只剩标题。
- 作答空间与预计步骤相称。检查 PDF 末页实际留白，不能仅依据源文件中的空白命令判断。

内置模板提供紧凑标题、左对齐章节与来源样式，可按学科调整。不要让字体或颜色选择影响数学表达正确性。

## 5. 插图只在帮助理解时加入

几何关系、数据趋势、算法流程与概念结构适合用图。精确图形优先用可验证的绘图或图表工具生成；节点、边、坐标、标签须与材料一致。

知识图示需要来源或“解释性重绘”标记。不要用图片生成模型绘制需精确核对的公式、数值图表或题目条件。仓库首页的概念封面属于宣传插图，不应自动插入学生每份试卷。

## 6. 导出后的实际检查

| 检查层 | 具体动作 |
| --- | --- |
| 文件 | 确认存在、有实际页面且可被 PDF 阅读器解析 |
| 文本 | 提取标题、中文、题号和分值；核查来源与答案对应 |
| 视觉 | 查看首页、公式密集页、长题页、表格页和末页，修复裁切、缺字和错误分页 |
| 一致性 | 对照来源清单、蓝图、源文件与 PDF，记录真实覆盖范围 |

数学提取可能不完整，不能只靠文本检查。Poppler 若报 Missing language pack，应配置对应编码数据或换可用阅读器；提取失败不能直接推断原 PDF 缺字，也不能据此跳过中文质量要求。

编译日志重点检查 Missing character、Undefined control sequence、Overfull box 与未解析引用。不是每条警告都导致失败，但缺字与内容截断必须解决。

无视觉能力时明确记录“未完成视觉检查”；只看了部分页面时记录抽查范围。PDF 本体交付与核验程度分别说明。
